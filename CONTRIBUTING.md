# Contributing

**Please note: This repository is a read-only mirror and does not accept pull requests.**

The `google-distributed-cloud-apis` repository is managed internally at Google. The source code is synchronized from our internal repositories using an automated process. Because of this architecture, we cannot merge pull requests directly on GitHub.

## Reporting Issues

While we cannot accept direct code contributions here, we welcome your feedback! If you discover a bug, have a feature request, or find an inconsistency with the [public documentation](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/apis/service-api-overview), please feel free to open an issue in this repository.

1. **Search existing issues** to see if your concern has already been reported.
2. **Open a new issue** with clear details to help us reproduce and understand the problem.

Our internal team monitors these issues, and any required changes will be made to the internal source of truth and synced back to this repository automatically.

## Contributor License Agreements

Even for opening issues, if you provide specific code snippets or suggestions that get incorporated into the codebase, you may be asked to sign a Contributor License Agreement (CLA) as per standard Google open-source guidelines.

* [Individual CLA](https://developers.google.com/open-source/cla/individual)
* [Corporate CLA](https://developers.google.com/open-source/cla/corporate)
